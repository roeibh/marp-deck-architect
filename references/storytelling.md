# Storytelling & Narrative Frameworks

How to structure a presentation that moves people. Each framework maps to one or more archetypes.

---

## Framework × Archetype Matrix

| Framework | Builder | Operator | Storyteller | Educator |
|-----------|---------|----------|-------------|----------|
| Problem → Solution → Impact | ✓ | **Default** | **Default** | |
| Situation → Complication → Resolution | | **Default** | ✓ | |
| What → So What → Now What | ✓ | | ✓ | **Default** |
| Chronological | ✓ | ✓ | | **Default** |
| Compare & Contrast | **Default** | | | ✓ |

**Default** = the recommended starting point for that archetype. ✓ = also works well.

---

## 1. Problem → Solution → Impact

**Best for**: Operator (proposals), Storyteller (pitches, demos)

```
HOOK - The problem in vivid terms (stat, story, or question)
PROBLEM (2-4 slides) - Make the audience feel the pain
SOLUTION (3-6 slides) - Your approach, high-level first
IMPACT (2-4 slides) - Before/after metrics, proof
NEXT STEPS (1-2 slides) - The ask or action
```

**Common mistake**: Rushing impact. If you have 20 slides: 4 problem, 8 solution, 6 impact, 2 close.

---

## 2. Situation → Complication → Resolution

**Best for**: Operator (strategy, board decks)

```
SITUATION (2-3 slides) - Current state, shared context
COMPLICATION (3-5 slides) - What changed, why status quo fails
RESOLUTION (4-8 slides) - Recommendation + evidence + plan
DECISION (1-2 slides) - What you need from the audience
```

**Common mistake**: Making Situation too long. The audience lives there - 2-3 slides to align, max.

---

## 3. What → So What → Now What

**Best for**: Educator (lessons), Storyteller (conference talks)

```
HOOK - Surprising fact or bold claim
WHAT (3-6 slides) - The thing: what it is, how it works
SO WHAT (3-5 slides) - Why it matters, implications
NOW WHAT (2-4 slides) - What to do about it, how to start
```

**Common mistake**: Weak "So What." Don't just say it's important - quantify, show examples.

---

## 4. Chronological

**Best for**: Builder (post-mortems), Educator (step-by-step), Operator (roadmaps)

```
CONTEXT (1-2 slides) - Setting the scene
PHASE 1-N (2-3 slides each) - Events + decisions + lessons
CURRENT STATE (1-2 slides) - Where we are now
FORWARD LOOK (2-3 slides) - What's next
TAKEAWAYS (1-2 slides) - Lessons learned
```

**Common mistake**: Treating it as a log. Each phase needs narrative - not just what, but why.

---

## 5. Compare & Contrast

**Best for**: Builder (technical evaluations), Educator (teaching tradeoffs)

```
CONTEXT (2-3 slides) - What we're deciding and evaluation criteria
OPTION A (3-5 slides) - How it works, strengths, weaknesses
OPTION B (3-5 slides) - Same structure
COMPARISON (1-2 slides) - Side-by-side table
RECOMMENDATION (1-2 slides) - Your pick + risk mitigation
```

**Common mistake**: Cherry-picking criteria. Be honest about the option you don't recommend.

## Universal Principles

### The Hook (slide 2, always)

- **Surprising stat**: "We deploy 300 times a day but catch bugs in production 40% of the time"
- **Provocative question**: "What if your CI pipeline is making you slower?"
- **Bold claim**: "Monoliths will outperform your microservices for the next 3 years"

### Pacing by Duration

| Duration | Builder | Operator | Storyteller | Educator |
|----------|---------|----------|-------------|----------|
| 5 min | 10-12 | 6-8 | 8-10 | 6-8 |
| 15 min | 18-25 | 12-16 | 15-20 | 12-16 |
| 30 min | 30-40 | 20-28 | 30-45 | 20-30 |
| 45 min | 40-55 | 28-36 | 40-55 | 35-50 |
